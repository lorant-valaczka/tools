# Changelog

## 1.5.0
- Decision log rebuilt as a hub plus one file per workstream, so parallel work (typography, iconography, imagery…) doesn't collide and no decision is lost.
- Session handoff rules: when to switch, how to close and open a session, a ready-to-paste starter message, a recommended folder structure.
- A heads-up at the start about the length of the process, and an estimate of sessions in the plan.
- README and changelog.
- License: CC BY-NC 4.0, with an additional permission for use in paid client work.

## 1.4.0
- Honest downloads and colour modes: RGB for screens, CMYK only from a real colour-managed export, originals kept distinct from previews.
- Source file handling: inventory first, originals never modified, exports in their own folder.
- Default layout for HTML brandbooks, a "what the book leaves out" list, contrast matrix.
- Optional modules: bento overview, live type specimen, logo colour explorer, clear-space diagram, misuse gallery, published snapshots.

## 1.3.0
- Typography golden rules, by Lóránt: four body levels with strong styles, display line-height and tracking, a mobile rule, text colour tiers.

## 1.2.0
- Three communication levels (newcomer, familiar, professional), set separately for the conversation and for the brandbook's readers, with a glossary and ready-to-forward supplier messages.

## 1.1.0
- Shorter messages: the user's part first, about five decision points per message.
- Application order as a default; a method for checking the mark at small sizes.

## 1.0.0
- First general version: three paths, eight phases with gates, decision log, working rules, identity references, brandbook structure, checklists. Works with or without Figma.
